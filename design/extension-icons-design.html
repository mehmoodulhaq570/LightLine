Extension icons: current and proposed

Zed's registry and its extension manifests have no icon field, so every extension except the three LightLine draws by hand (Prettier, Material Icon Theme, Dracula) gets the same grey package glyph. The proposal gives every extension an icon from what LightLine does know, without any downloads. An installed extension's icon comes from its own files. One that isn't installed yet gets a monogram that's always the same for the same extension.

Where each icon comes from

  1. Color themes, once installed: a tile in the theme's own editor background, with three short lines of "code" in its keyword, string and function colours. Catppuccin, Gruvbox and Tokyo Night look like themselves, light themes look light, and you can tell themes apart at a glance.
  2. Icon themes, once installed: the theme's own folder icon from its SVGs, which is what Material's tile does today.
  3. Languages, once installed: the language's file icon from the active icon theme (Lua's moon, Zig's bolt), else LightLine's built-in icon for it.
  4. Anything not installed yet: a monogram. Before installing, LightLine only knows the extension's id. The first letters of its words become the letters (tokyo-night → TN; one word gives one letter, nord → N), on one of eight colours picked from the id. The same extension always gets the same tile, and neighbours rarely match.
  5. Prettier, Material and Dracula keep the marks LightLine draws for them.

Speed and privacy

  • No network. No icon or avatar is fetched for each result. That would be one request per row, slow on a poor connection, limited to 60 an hour by GitHub without a login, and against LightLine's rule to use the network only when asked.
  • Worked out once. A theme's colours, folder icon or language icon are read when the extension is installed, or when LightLine first lists its extensions, and kept with it. Painting never re-reads theme files.
  • Cheap to draw. A monogram is one filled square and two letters. A swatch is a square and three short bars. Icons come from the shared atlas. Idle stays at 0 wakeups.
  • No guessing. A result's kind isn't guessed from its name ("…-theme"). A monogram says only what's known.
