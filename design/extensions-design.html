LightLine Extensions: current and proposed

On the left is a screenshot of the panel today. On the right is the proposed panel, drawn at the same 125% scale in LightLine's own colours, in the style of the new Source Control and Run and Debug panels. It's the same catalogue (the Zed registry), the same three featured picks, the same install and uninstall, and the same workspace summary. What changes is the layout: extensions become compact rows like VS Code's instead of 132 px cards, and installed and featured extensions are shown together, so the whole picture fits without scrolling.

Hover rows in the mock.

What changes

  1. Extensions are 62 px rows, not 132 px cards. Each shows a 36 px icon, then its name and version, its description and its publisher with its kind (Formatter, Icon theme, Color theme) as coloured text, with one action at the right. The bordered card, the coloured bar on its edge and the kind's pill go. Three extensions take 186 px instead of 420.
  2. Installed and featured are shown together as sections, as in VS Code: INSTALLED, then FEATURED. The Marketplace / Installed switch goes, so you don't have to switch to see what you have.
  3. Filters are small chips under the search box (All, Themes, Formatters). Today they're three 28 px buttons in a row of their own, and they only show on the Marketplace tab.
  4. One compact action per row. A blue Install button. When installed, a green ✓; point at the row for Uninstall. Today the green "✓ Installed" button uninstalls when clicked, with nothing to say so. While installing, Installing…; for Prettier, which isn't downloaded, Checking….
  5. Searching shows the registry's matches under MARKETPLACE with a count, and says plainly what installs today: themes, and languages with a Tree-sitter grammar.
  6. "Your workspace" becomes an IN USE section of 22 px rows: Formatting, File icons, Color theme. Color theme still opens the theme picker. The card's border and the "● Ready" badge go.
  7. The header gets a ··· menu beside Refresh: Show Installed, Show Featured, Check for Updates (re-reads the registry), Open Extensions Folder.
  8. Icons are drawn from the icon atlas like the rest of the UI. Today the search glass, funnel and ✕ are hand-drawn 1 px GDI lines, and Dracula's dot is a GDI Ellipse.

Speed

  • Nothing new runs or downloads. The registry is still fetched only when you search (or press Refresh), and installs work as today.
  • Fewer shapes per extension. Each card drew a border, an edge bar, an icon tile, a kind pill and a button card. A row draws a hover fill, an icon and one small button.
  • Hover redraws one row (the same Hot targets as Source Control and Run and Debug), with no timers. Idle stays at 0 wakeups.

Open questions

  • Uninstall on hover (as drawn), or a ⚙ menu per installed extension like VS Code (Uninstall, Copy ID, Open Folder)?
  • Extension details page (README, version history) when a row is clicked would be new work and need the network. It's left for later; clicking a row does nothing for now, as today.
