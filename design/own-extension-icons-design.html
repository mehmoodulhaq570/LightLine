Icons for LightLine's Own Extensions Approved with all recommendations 2026-11-25; built

Today LightLine Themes shows a plain L before it's installed, and C and C++ Snippets always shows LC. These are the same letter tiles any unknown extension gets. Proposed: each gets an icon drawn from the LightLine mark (the indigo tile, its violet-to-blue edge and the bolt), so our own extensions are recognizably ours, before and after they're installed.

Shown at 4× on LightLine Daylight's and LightLine Midnight's sidebar colors. LightLine Themes is split by its own bolt: the Daylight half on one side, the Contrast half on the other. C and C++ Snippets puts the bolt between braces, for code that appears at once.

In the Extensions panel

Dracula is drawn here as a letter tile only to keep the crop simple; in LightLine it shows its own colors. Dashed green marks what's new.

At the sizes LightLine draws them

A row's icon is 36 logical pixels, so 36, 45 or 72 real pixels at 100%, 125% and 200%. Each size is drawn from the SVG at that exact size, never stretched.

Options

Recommended Themes A: split by the bolt

One tile, half Daylight and half Contrast, with the bolt as the seam. It says "two themes, from LightLine" at a glance, and the halves use the themes' real colors.

Themes B: two windows

A light and a dark window on the indigo tile, with a small bolt. More literal; at 36 px the windows' code lines are only a pixel or two tall.

Recommended Snippets A: braces around the bolt

Code in an instant. The braces read as C at once, and the bolt keeps it in the LightLine family.

Snippets B: a tab stop

A small block of code with a dashed placeholder, the part of a snippet Tab moves to. Closer to how snippets work, but quieter as an icon.

The same family for later

When LightLine publishes another extension, it gets the tile for its kind without new art, until it earns its own. A second snippet pack would share the braces until it gets its own.

How it's built

  • Where the art lives: each icon is an SVG of about 1.5 KB built into LightLine, beside the file-type icons. It's there before anything is downloaded, offline too, and needs no change to the extensions themselves (Zed's format has no icon).
  • Which rows get it: an entry LightLine's list says LightLine publishes (publisher = "LightLine", ids starting lightline-) gets its own icon, or its kind's when it has none. It wins over the color swatch the theme pack shows today once installed.
  • How it's drawn: through the icon atlas, like the file icons: rasterized once at the exact size shown, then copied with AlphaBlend. No icon handles, nothing per frame.
  • Checks: a test renders every one at 36, 45 and 72 px and checks it isn't empty; live, the panel in Midnight, Daylight and Contrast against these crops, with the repaint check.
  • Docs: a line in CHANGELOG.md; the icons also go in lightline-extensions' READMEs.
